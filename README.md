## 📋 About The Project

**TRADEXPO.INC** is a professional, multi-page B2B website designed for an electronics retail company that supplies large-scale electronic products to:

- 🏢 **Businesses** (Corporate offices, IT departments)
- 🏫 **Schools** (Computer labs, science equipment)
- 🏥 **Hospitals** (Medical electronics, monitoring systems)

---

## 🖥️ Pages Included

| Page | Description |
|------|-------------|
| **Home** | Hero section, stats, featured products, testimonials |
| **About** | Company story, mission, vision, team, values |
| **Products** | 8+ product categories with images and inquiry buttons |
| **Contact** | Contact form, Google Maps, business hours |

---

## 🛠️ Technologies Used

- **HTML5** - Semantic markup
- **CSS3** - Custom styling, Flexbox, Grid, Animations
- **JavaScript** - Interactivity, form validation, smooth scrolling
- **Font Awesome 6** - Icons
- **Google Fonts** - Playfair Display + Inter
- **Unsplash** - Professional stock photography
